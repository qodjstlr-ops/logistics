# 자재통합관리

Python 3.12와 openpyxl 3.1.5를 사용하는 미출고 조회용 초기 웹 애플리케이션입니다.

```bash
cd /workspace/logistics
/workspace/materials-venv/bin/python app.py --port 8000
```

환경이 없다면 Python 가상환경을 만들고 `python -m pip install -r requirements.txt`로 설치합니다.

PP610 및 PP620 엑셀을 업로드하고 FCID 또는 제조오더번호로 검색합니다. 이동잔량 1 이상인 미출고 자재가 있는 모든 제조오더를 FCID·제조오더번호별로 묶어 표시합니다. 미출고 비율은 제조오더 전체 자재 행 수 기준으로 계산하며 10% 이하는 펼쳐서, 초과는 접어서 표시합니다. 접힌 항목은 클릭해 상세 자재를 볼 수 있습니다. FCID 매칭 누락·충돌과 잔량 오류는 경고하며 해당 제조오더는 결과에서 제외합니다. 업로드 파일은 디스크에 저장하지 않습니다.

이 서버는 로컬 개발용입니다. 외부 배포 전 사내 로그인, 접근 제어, HTTPS와 업로드 자원 제한을 포함한 운영 구성을 별도로 마련해야 합니다. 수입화물과 포장 일정은 향후 기능입니다.

검증: `/workspace/materials-venv/bin/python -m unittest discover -s tests -v`

## Render 테스트 배포

저장소 루트에 Dockerfile과 render.yaml을 제공합니다. 배포 컨테이너에는 소스와 정적 파일만 포함되며 첨부 엑셀은 포함하지 않습니다.

1. 코드를 본인의 GitHub 저장소에 반영합니다.
2. Render에 로그인하고 New → Blueprint에서 해당 저장소를 연결합니다.
3. render.yaml의 무료 테스트 서비스를 확인해 배포합니다. 무료 요금제 제공 여부는 Render에서 확인합니다.
4. 배포 성공 후 Render가 제공하는 서비스 주소로 접속해 두 엑셀 업로드와 검색을 확인합니다.

자동 재배포는 비활성화되어 있습니다. 무료 서비스는 유휴 시 중지되거나 자원 제한에 걸릴 수 있습니다. 대용량 엑셀 분석은 배포 환경에서도 별도로 검증해야 합니다. 로그인 없는 테스트 버전이므로 외부 테스트에는 가상 데이터를 사용합니다. 실제 사내 자료를 다루는 운영 배포는 인증과 자원 제한 등을 추가한 후 진행합니다.
